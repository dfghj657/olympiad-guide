📚 Содержание

    I. Уравнения первого порядка

    Основные понятия и задача Коши 1-й порядок

    Общий вид: \(F(x, y, y') = 0\) или в нормальной форме \(y' = f(x, y)\).

    Задача Коши: найти решение с условием \(y(x_0) = y_0\).

    Теорема существования и единственности (Пикар): если \(f\) и \(\frac{\partial f}{\partial y}\) непрерывны в окрестности точки \((x_0, y_0)\), то решение задачи Коши существует и единственно в некоторой окрестности \(x_0\).

    Общее решение — семейство \(y = \varphi(x, C)\); частное — при конкретном \(C\); особое — решение, в каждой точке которого нарушается единственность (огибающая семейства).

    Пример нарушения единственности: \(y' = 2\sqrt{y}\), \(y(0) = 0\): решения \(y \equiv 0\) и \(y = x^2\) при \(x \ge 0\).

    С разделяющимися переменными 1-й порядок

    Вид: \(y' = f(x)\,g(y)\) или \(M_1(x)N_1(y)\,dx + M_2(x)N_2(y)\,dy = 0\).

    Метод: разделить переменные и проинтегрировать:

    \[\int \frac{dy}{g(y)} = \int f(x)\,dx + C.\]

    ⚠ Не забудьте решения \(g(y) = 0\) — они могли потеряться при делении.

    Приводящиеся: \(y' = f(ax + by + c)\) — замена \(z = ax + by + c\), тогда \(z' = a + b f(z)\).

    Пример: \(y' = xy\). \(\frac{dy}{y} = x\,dx \Rightarrow \ln|y| = \frac{x^2}{2} + C \Rightarrow y = Ce^{x^2/2}\) (включая \(y \equiv 0\) при \(C = 0\)).

    Однородные уравнения 1-й порядок

    Вид: \(y' = f\!\left(\frac{y}{x}\right)\), или \(M\,dx + N\,dy = 0\), где \(M, N\) — однородные функции одной степени: \(M(tx, ty) = t^k M(x, y)\).

    Метод: замена \(y = ux\), \(y' = u + xu'\) даёт уравнение с разделяющимися переменными:

    \[x\,u' = f(u) - u.\]

    Приводящиеся к однородным: \(y' = f\!\left(\frac{a_1x + b_1y + c_1}{a_2x + b_2y + c_2}\right)\).

    • Если \(a_1b_2 - a_2b_1 \ne 0\): сдвиг \(x = X + x_0,\ y = Y + y_0\), где \((x_0, y_0)\) — точка пересечения прямых \(a_ix + b_iy + c_i = 0\).
    • Если \(a_1b_2 - a_2b_1 = 0\): замена \(z = a_1x + b_1y\) — разделяющиеся переменные.
    Пример: \(y' = \frac{x + y}{x}\). \(u + xu' = 1 + u \Rightarrow u' = \frac1x \Rightarrow u = \ln|x| + C \Rightarrow y = x(\ln|x| + C)\).

    Линейные уравнения первого порядка 1-й порядок

    Вид: \(y' + p(x)\,y = q(x)\).

    Способ 1 — интегрирующий множитель: умножить на \(\mu = e^{\int p\,dx}\), тогда левая часть — \((\mu y)'\):

    \[y = e^{-\int p\,dx}\left(\int q\,e^{\int p\,dx}\,dx + C\right).\]

    Способ 2 — Бернулли: \(y = u(x)\,v(x)\); \(v\) выбирают из \(v' + pv = 0\), затем \(u' v = q\).

    Способ 3 — вариация постоянной (Лагранжа): решить однородное \(y = Ce^{-\int p\,dx}\), затем считать \(C = C(x)\) и подставить.

    Пример: \(y' + \frac{y}{x} = x^2\). \(\mu = x\): \((xy)' = x^3 \Rightarrow xy = \frac{x^4}{4} + C \Rightarrow y = \frac{x^3}{4} + \frac{C}{x}\).

    Уравнение Бернулли 1-й порядок

    Вид: \(y' + p(x)\,y = q(x)\,y^n\), \(n \ne 0, 1\).

    Метод: разделить на \(y^n\) и сделать замену \(z = y^{1-n}\) — получится линейное:

    \[z' + (1-n)\,p(x)\,z = (1-n)\,q(x).\]

    При \(n > 0\) не забудьте решение \(y \equiv 0\). Можно решать и сразу подстановкой \(y = uv\).

    Пример: \(y' + y = xy^2\). \(z = \frac1y\): \(z' - z = -x\). \((ze^{-x})' = -xe^{-x} \Rightarrow ze^{-x} = (x+1)e^{-x} + C\). Ответ: \(y = \frac{1}{x + 1 + Ce^{x}}\), а также \(y \equiv 0\).

    Уравнение Риккати 1-й порядок

    Вид: \(y' = P(x)\,y^2 + Q(x)\,y + R(x)\).

    В общем случае в квадратурах не решается. Но если известно одно частное решение \(y_1\) (обычно угадывают в виде \(\frac{a}{x}\), \(ax + b\), \(e^{ax}\)…), то замена

    \[y = y_1 + \frac{1}{z}\]

    сводит его к линейному уравнению \(z' = -(2Py_1 + Q)\,z - P\).

    Замена \(y = -\frac{u'}{P u}\) сводит Риккати к линейному уравнению 2-го порядка.

    Пример: \(y' = y^2 - \frac{2}{x^2}\). Ищем \(y_1 = \frac{a}{x}\): \(-a = a^2 - 2 \Rightarrow a = 1\). Подстановка \(y = \frac1x + \frac1z\) даёт \(z' + \frac{2}{x}z = -1 \Rightarrow z = -\frac{x}{3} + \frac{C}{x^2}\). Ответ: \(y = \frac1x + \frac{3x^2}{3C - x^3}\).

    Уравнения в полных дифференциалах 1-й порядок

    Вид: \(M(x,y)\,dx + N(x,y)\,dy = 0\), где \(\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}\).

    Метод: существует \(F\) с \(dF = M\,dx + N\,dy\), решение: \(F(x, y) = C\).

    \[F = \int M\,dx + \varphi(y),\qquad \varphi'(y) = N - \frac{\partial}{\partial y}\int M\,dx.\]
    Пример: \((2xy + 1)\,dx + (x^2 + 2y)\,dy = 0\). \(M_y = 2x = N_x\). \(F = x^2y + x + \varphi(y)\), \(\varphi' = 2y\). Ответ: \(x^2y + x + y^2 = C\).

    Интегрирующий множитель 1-й порядок

    Если \(M_y \ne N_x\), ищем \(\mu\), при котором \(\mu M\,dx + \mu N\,dy = 0\) — в полных дифференциалах.

    • \(\mu = \mu(x)\), если \(\dfrac{M_y - N_x}{N}\) зависит только от \(x\): \(\mu = \exp\!\int \dfrac{M_y - N_x}{N}\,dx\).
    • \(\mu = \mu(y)\), если \(\dfrac{N_x - M_y}{M}\) зависит только от \(y\): \(\mu = \exp\!\int \dfrac{N_x - M_y}{M}\,dy\).
    • Полезные комбинации: \(d(xy) = y\,dx + x\,dy\), \(d\!\left(\frac{y}{x}\right) = \frac{x\,dy - y\,dx}{x^2}\), \(d\ln\frac{y}{x}\), \(d\arctan\frac{y}{x} = \frac{x\,dy - y\,dx}{x^2 + y^2}\), \(d\frac{x^2+y^2}{2} = x\,dx + y\,dy\).
    Пример: \((x^2 + y)\,dx - x\,dy = 0\). \(\frac{M_y - N_x}{N} = \frac{2}{-x}\), \(\mu = x^{-2}\). Получаем \(d\!\left(x - \frac{y}{x}\right) = 0\). Ответ: \(y = x^2 - Cx\).

    Не разрешённые относительно производной. Лагранж и Клеро 1-й порядок

    Вид: \(F(x, y, y') = 0\). Обозначаем \(p = y'\) и вводим параметр.

    • \(y = f(x, p)\): продифференцировать по \(x\): \(p = f_x + f_p\,\frac{dp}{dx}\) — уравнение на \(p(x)\).
    • \(x = f(y, p)\): дифференцировать по \(y\): \(\frac1p = f_y + f_p\,\frac{dp}{dy}\).

    Уравнение Лагранжа: \(y = x\,\varphi(y') + \psi(y')\). После дифференцирования получается линейное уравнение относительно \(x(p)\):

    \[\big(p - \varphi(p)\big)\frac{dx}{dp} - \varphi'(p)\,x = \psi'(p).\]

    Уравнение Клеро (\(\varphi(p) = p\)): \(y = xy' + \psi(y')\).

    • Общее решение — семейство прямых: \(y = Cx + \psi(C)\).
    • Особое решение (огибающая) параметрически: \(x = -\psi'(p),\ y = -p\,\psi'(p) + \psi(p)\).

    Особые решения ищут через \(p\)-дискриминант: исключить \(p\) из \(F = 0,\ \frac{\partial F}{\partial p} = 0\) и проверить подстановкой.

    Пример: \(y = xy' + (y')^2\). Общее: \(y = Cx + C^2\). Особое: \(x = -2p,\ y = -p^2 \Rightarrow y = -\frac{x^2}{4}\).

    II. Уравнения высших порядков: понижение порядка

    \(y^{(n)} = f(x)\) понижение порядка

    Метод: \(n\) раз проинтегрировать; появятся \(n\) констант. Формула Коши:

    \[y = \frac{1}{(n-1)!}\int_{x_0}^{x}(x - t)^{n-1} f(t)\,dt + C_1x^{n-1} + \dots + C_n.\]
    Пример: \(y'' = \sin x \Rightarrow y = -\sin x + C_1x + C_2\).

    Нет искомой функции: \(F(x, y^{(k)}, \dots, y^{(n)}) = 0\) понижение порядка

    Метод: замена \(z(x) = y^{(k)}\) понижает порядок на \(k\).

    Пример: \(xy'' = y'\). \(p = y'\): \(xp' = p \Rightarrow p = C_1x \Rightarrow y = \frac{C_1x^2}{2} + C_2\).

    Нет независимой переменной: \(F(y, y', y'') = 0\) понижение порядка

    Метод: считаем \(y' = p(y)\) функцией от \(y\):

    \[y'' = p\,\frac{dp}{dy},\qquad y''' = p\,\frac{d}{dy}\!\left(p\,\frac{dp}{dy}\right).\]

    Частный случай — \(y'' = f(y)\) (закон Ньютона): домножить на \(y'\) — «интеграл энергии» \(\frac{(y')^2}{2} = \int f(y)\,dy + C_1\).

    Пример: \(yy'' = (y')^2\). \(yp\,\frac{dp}{dy} = p^2 \Rightarrow p = C_1y \Rightarrow y = C_2e^{C_1x}\).

    Однородные относительно \(y, y', y''\) понижение порядка

    Вид: \(F(x, ty, ty', ty'') = t^k F(x, y, y', y'')\).

    Метод: замена \(y' = y\,z(x)\), тогда \(y'' = y(z' + z^2)\); \(y\) сокращается.

    Точная производная: если левую часть можно записать как \(\frac{d}{dx}\Phi(x, y, y') = 0\), то \(\Phi = C_1\) — порядок понижен.

    Пример: \(yy'' + (y')^2 = 0\) — это \((yy')' = 0\), откуда \(yy' = C_1\), \(y^2 = C_1x + C_2\).

    III. Линейные уравнения n-го порядка

    Структура решения. Вронскиан линейные

    Вид: \(y^{(n)} + p_1(x)y^{(n-1)} + \dots + p_n(x)y = f(x)\).

    • Решения однородного уравнения (\(f = 0\)) образуют \(n\)-мерное линейное пространство; базис — фундаментальная система решений (ФСР) \(y_1, \dots, y_n\).
    • Общее решение неоднородного = общее решение однородного + любое частное: \(y = C_1y_1 + \dots + C_ny_n + y_{\text{ч}}\).
    • Принцип суперпозиции: если \(f = f_1 + f_2\), то \(y_{\text{ч}} = y_{\text{ч}1} + y_{\text{ч}2}\).
    • Вронскиан \(W = \det\big(y_j^{(i)}\big)\): решения линейно независимы \(\iff W \ne 0\).
    • Формула Лиувилля–Остроградского: \(W(x) = W(x_0)\,\exp\!\left(-\int_{x_0}^x p_1(t)\,dt\right)\).

    Понижение порядка при известном решении \(y_1\) уравнения \(y'' + p y' + q y = 0\):

    \[y_2 = y_1 \int \frac{e^{-\int p\,dx}}{y_1^2}\,dx.\]

    Однородные с постоянными коэффициентами линейные

    Вид: \(a_0y^{(n)} + a_1y^{(n-1)} + \dots + a_ny = 0\), \(a_i = \text{const}\).

    Ищем \(y = e^{\lambda x}\) → характеристическое уравнение \(a_0\lambda^n + a_1\lambda^{n-1} + \dots + a_n = 0\).

    КорниВклад в ФСР
    Вещественный \(\lambda\) кратности 1\(e^{\lambda x}\)
    Вещественный \(\lambda\) кратности \(k\)\(e^{\lambda x},\ xe^{\lambda x},\ \dots,\ x^{k-1}e^{\lambda x}\)
    Пара \(\alpha \pm i\beta\)\(e^{\alpha x}\cos\beta x,\ e^{\alpha x}\sin\beta x\)
    Пара \(\alpha \pm i\beta\) кратности \(k\)\(x^j e^{\alpha x}\cos\beta x,\ x^j e^{\alpha x}\sin\beta x,\ j = 0..k-1\)
    Примеры:
    \(y'' - 3y' + 2y = 0\): \(\lambda = 1, 2\) → \(y = C_1e^x + C_2e^{2x}\).
    \(y'' + 2y' + y = 0\): \(\lambda = -1\) (кратный) → \(y = (C_1 + C_2x)e^{-x}\).
    \(y'' + 2y' + 5y = 0\): \(\lambda = -1 \pm 2i\) → \(y = e^{-x}(C_1\cos 2x + C_2\sin 2x)\).
    \(y'' + \omega^2 y = 0\) (гармонический осциллятор) → \(y = C_1\cos\omega x + C_2\sin\omega x\).

    Неоднородные: метод неопределённых коэффициентов линейные

    Работает при постоянных коэффициентах и специальной правой части:

    \[f(x) = e^{\alpha x}\big(P_m(x)\cos\beta x + Q_l(x)\sin\beta x\big).\]

    Частное решение ищем в виде

    \[y_{\text{ч}} = x^{s}\,e^{\alpha x}\big(R_k(x)\cos\beta x + T_k(x)\sin\beta x\big),\quad k = \max(m, l),\]

    где \(s\) — кратность числа \(\alpha + i\beta\) как корня характеристического уравнения (\(s = 0\), если не корень). Случай \(s > 0\) — резонанс.

    Правая частьВид частного решения (без резонанса)
    \(P_m(x)\)\(R_m(x)\)
    \(Ae^{\alpha x}\)\(Be^{\alpha x}\)
    \(A\cos\beta x + B\sin\beta x\)\(C\cos\beta x + D\sin\beta x\)
    \(P_m(x)e^{\alpha x}\)\(R_m(x)e^{\alpha x}\)
    Пример (резонанс): \(y'' - 3y' + 2y = e^x\). \(\alpha = 1\) — простой корень, \(s = 1\): \(y_{\text{ч}} = Axe^x\). Подстановка: \(-A = 1\). Ответ: \(y = C_1e^x + C_2e^{2x} - xe^x\).

    Неоднородные: вариация постоянных (Лагранжа) линейные

    Универсальный метод для любой правой части (и переменных коэффициентов), если известна ФСР.

    Для \(y'' + p(x)y' + q(x)y = f(x)\) ищем \(y = C_1(x)y_1 + C_2(x)y_2\), где

    \[\begin{cases} C_1'y_1 + C_2'y_2 = 0,\\ C_1'y_1' + C_2'y_2' = f(x), \end{cases}\qquad C_1' = -\frac{y_2 f}{W},\quad C_2' = \frac{y_1 f}{W}.\]

    Для порядка \(n\): первые \(n-1\) уравнений системы равны нулю, последнее — \(\sum C_i' y_i^{(n-1)} = f\) (при старшем коэффициенте 1).

    Пример: \(y'' + y = \frac{1}{\cos x}\). \(y_1 = \cos x,\ y_2 = \sin x,\ W = 1\). \(C_1' = -\tan x \Rightarrow C_1 = \ln|\cos x|\); \(C_2' = 1 \Rightarrow C_2 = x\). Ответ: \(y = C_1\cos x + C_2\sin x + \cos x\ln|\cos x| + x\sin x\).

    Уравнение Эйлера линейные

    Вид: \(a_0x^ny^{(n)} + a_1x^{n-1}y^{(n-1)} + \dots + a_ny = f(x)\), \(a_i = \text{const}\).

    Метод: замена \(x = e^t\) (при \(x > 0\)) даёт уравнение с постоянными коэффициентами. Для однородного проще сразу искать \(y = x^k\):

    \[x^2y'' + axy' + by = 0 \ \Rightarrow\ k(k-1) + ak + b = 0.\]
    Корни \(k\)Решения
    различные вещественные\(x^{k_1},\ x^{k_2}\)
    кратный\(x^{k},\ x^{k}\ln x\)
    \(\alpha \pm i\beta\)\(x^{\alpha}\cos(\beta\ln x),\ x^{\alpha}\sin(\beta\ln x)\)

    Обобщение: \((ax + b)^n y^{(n)} + \dots\) — замена \(ax + b = e^t\).

    Пример: \(x^2y'' - 2xy' + 2y = 0\). \(k^2 - 3k + 2 = 0\), \(k = 1, 2\). Ответ: \(y = C_1x + C_2x^2\).

    Решение степенными рядами. Специальные функции линейные

    Для \(y'' + p(x)y' + q(x)y = 0\):

    • Обыкновенная точка (\(p, q\) аналитичны в \(x_0\)): ищем \(y = \sum a_k(x - x_0)^k\), получаем рекуррентную формулу для \(a_k\).
    • Регулярная особая точка (\((x-x_0)p\) и \((x-x_0)^2q\) аналитичны) — метод Фробениуса: \(y = (x-x_0)^r\sum a_k(x-x_0)^k\), где \(r\) — корень определяющего уравнения \(r(r-1) + p_0r + q_0 = 0\).
    УравнениеРешения
    Бесселя: \(x^2y'' + xy' + (x^2 - \nu^2)y = 0\)\(J_\nu(x),\ Y_\nu(x)\)
    Лежандра: \((1 - x^2)y'' - 2xy' + n(n+1)y = 0\)многочлены \(P_n(x)\)
    Эрмита: \(y'' - 2xy' + 2ny = 0\)многочлены \(H_n(x)\)
    Эйри: \(y'' - xy = 0\)\(\mathrm{Ai}(x),\ \mathrm{Bi}(x)\)
    Гипергеометрическое Гаусса: \(x(1-x)y'' + [c - (a+b+1)x]y' - aby = 0\)\({}_2F_1(a, b; c; x)\)
    Пример: \(y'' + y = 0\), \(y = \sum a_kx^k\): \(a_{k+2} = -\frac{a_k}{(k+1)(k+2)}\) — получаются ряды для \(\cos x\) и \(\sin x\).

    Краевые задачи. Задача Штурма–Лиувилля линейные

    Условия задаются в двух точках: \(y(a) = A,\ y(b) = B\) (или на производные). Решение может не существовать или быть не единственным.

    Задача Штурма–Лиувилля: \(-(p(x)y')' + q(x)y = \lambda\,r(x)y\) с однородными краевыми условиями. Собственные значения вещественны, \(\lambda_1 \lt \lambda_2 \lt \dots \to \infty\), собственные функции ортогональны с весом \(r\).

    Пример: \(y'' + \lambda y = 0,\ y(0) = y(l) = 0\): \(\lambda_n = \left(\frac{\pi n}{l}\right)^2\), \(y_n = \sin\frac{\pi n x}{l}\) — основа метода Фурье.

    IV. Системы дифференциальных уравнений

    Метод исключения. Первые интегралы системы

    Исключение: выразить одну неизвестную из одного уравнения, подставить в другое → одно уравнение более высокого порядка.

    Первые интегралы: для системы в симметричной форме \(\frac{dx}{X} = \frac{dy}{Y} = \frac{dz}{Z}\) ищем интегрируемые комбинации (свойство равных дробей: \(\frac{dx + dy}{X + Y}\), \(\frac{x\,dx + y\,dy}{xX + yY}\) и т. п.).

    Пример: \(x' = y,\ y' = -x\). Отсюда \(x'' = -x\): \(x = C_1\cos t + C_2\sin t\), \(y = x'\). Первый интеграл: \(x^2 + y^2 = C\).

    Линейные системы с постоянными коэффициентами системы

    Вид: \(\vec{x}\,' = A\vec{x} + \vec{f}(t)\).

    Метод Эйлера: ищем \(\vec{x} = \vec{v}e^{\lambda t}\), где \(\det(A - \lambda E) = 0\), \((A - \lambda E)\vec{v} = 0\).

    • Разные вещественные \(\lambda_i\): \(\vec{x} = \sum C_i\vec{v}_ie^{\lambda_it}\).
    • Комплексные \(\lambda = \alpha \pm i\beta\): берём \(\mathrm{Re}\) и \(\mathrm{Im}\) от \(\vec{v}e^{\lambda t}\).
    • Кратный \(\lambda\) без полного набора векторов: \(\vec{x}_2 = (\vec{v}t + \vec{w})e^{\lambda t}\), где \((A - \lambda E)\vec{w} = \vec{v}\) (присоединённый вектор).

    Матричная экспонента: \(\vec{x}(t) = e^{At}\vec{x}_0 + \int_0^t e^{A(t-s)}\vec{f}(s)\,ds\), \(e^{At} = \sum\frac{(At)^k}{k!}\) (удобно считать через жорданову форму).

    Пример: \(x' = x + 2y,\ y' = 2x + y\). \(\lambda_1 = 3,\ \vec{v}_1 = (1, 1)\); \(\lambda_2 = -1,\ \vec{v}_2 = (1, -1)\). \(\begin{pmatrix}x\\y\end{pmatrix} = C_1e^{3t}\begin{pmatrix}1\\1\end{pmatrix} + C_2e^{-t}\begin{pmatrix}1\\-1\end{pmatrix}\).

    Фазовая плоскость и особые точки системы

    Для системы \(\vec{x}\,' = A\vec{x}\), \(A\) — матрица \(2\times2\), \(\tau = \mathrm{tr}\,A\), \(\Delta = \det A\):

    УсловиеТип точки покоя
    \(\Delta \lt 0\)Седло (неустойчиво)
    \(\Delta \gt 0,\ \tau^2 \gt 4\Delta\)Узел (устойчив при \(\tau \lt 0\))
    \(\Delta \gt 0,\ \tau^2 = 4\Delta\)Вырожденный или дикритический узел
    \(\Delta \gt 0,\ \tau^2 \lt 4\Delta,\ \tau \ne 0\)Фокус (устойчив при \(\tau \lt 0\))
    \(\Delta \gt 0,\ \tau = 0\)Центр (устойчив, но не асимптотически)
    \(\Delta = 0\)Вырожденный случай: прямая из точек покоя

    Устойчивость по Ляпунову системы

    Для нелинейной системы \(\vec{x}\,' = \vec{F}(\vec{x})\) с точкой покоя \(\vec{x}_0\) рассматриваем линеаризацию с матрицей Якоби \(J = \frac{\partial \vec F}{\partial \vec x}(\vec{x}_0)\).

    • Теорема об устойчивости по первому приближению: все \(\mathrm{Re}\,\lambda_i \lt 0\) → асимптотически устойчива; есть \(\mathrm{Re}\,\lambda_i \gt 0\) → неустойчива. Если есть \(\mathrm{Re}\,\lambda = 0\) — нужен дополнительный анализ.
    • Функция Ляпунова \(V(\vec{x}) \gt 0\) (при \(\vec x \ne \vec x_0\)) с \(\dot V = \nabla V\cdot\vec{F} \le 0\) → устойчивость; \(\dot V \lt 0\) → асимптотическая устойчивость.
    • Критерий Рауса–Гурвица для \(\lambda^2 + a_1\lambda + a_2\): устойчиво \(\iff a_1 \gt 0,\ a_2 \gt 0\); для \(\lambda^3 + a_1\lambda^2 + a_2\lambda + a_3\): \(a_i \gt 0,\ a_1a_2 \gt a_3\).
    Пример: маятник с трением \(\ddot\theta + k\dot\theta + \sin\theta = 0\), \(k \gt 0\): \(V = \frac{\dot\theta^2}{2} + 1 - \cos\theta\), \(\dot V = -k\dot\theta^2 \le 0\) — нижнее положение устойчиво.

    V. Уравнения в частных производных

    Уравнения первого порядка. Метод характеристик УЧП

    Линейное однородное: \(a(x, y)u_x + b(x, y)u_y = 0\). Находим первый интеграл \(\psi(x, y) = C\) уравнения \(\frac{dx}{a} = \frac{dy}{b}\); общее решение \(u = F(\psi(x, y))\), \(F\) — произвольная функция.

    Квазилинейное: \(a\,u_x + b\,u_y = c\) (\(a, b, c\) зависят от \(x, y, u\)). Характеристическая система

    \[\frac{dx}{a} = \frac{dy}{b} = \frac{du}{c}\]

    даёт два первых интеграла \(\psi_1 = C_1,\ \psi_2 = C_2\); общее решение: \(\Phi(\psi_1, \psi_2) = 0\).

    Пример (уравнение переноса): \(u_t + cu_x = 0,\ u(x, 0) = \varphi(x)\). Характеристики \(x - ct = \text{const}\). Ответ: \(u = \varphi(x - ct)\) — профиль бежит со скоростью \(c\).
    Пример (Хопф/Бюргерс без вязкости): \(u_t + uu_x = 0\): \(u = \varphi(x - ut)\) (неявно); характеристики могут пересекаться — образуются ударные волны.

    Классификация уравнений второго порядка УЧП

    Вид: \(Au_{xx} + 2Bu_{xy} + Cu_{yy} + (\text{младшие члены}) = 0\).

    \(D = B^2 - AC\)ТипКанонический видПрототип
    \(D \gt 0\)Гиперболический\(u_{\xi\eta} + \dots = 0\)Волновое
    \(D = 0\)Параболический\(u_{\eta\eta} + \dots = 0\)Теплопроводности
    \(D \lt 0\)Эллиптический\(u_{\xi\xi} + u_{\eta\eta} + \dots = 0\)Лапласа

    Приведение к каноническому виду: характеристическое уравнение \(A\,dy^2 - 2B\,dx\,dy + C\,dx^2 = 0\), т. е. \(\frac{dy}{dx} = \frac{B \pm \sqrt{D}}{A}\). Его интегралы дают новые переменные \(\xi, \eta\).

    Пример: \(u_{xx} - 4u_{xy} + 3u_{yy} = 0\). \(D = 4 - 3 = 1 \gt 0\), \(\frac{dy}{dx} = -2 \pm 1\): \(\xi = y + x,\ \eta = y + 3x\). Получаем \(u_{\xi\eta} = 0\), \(u = f(x + y) + g(3x + y)\).

    Волновое уравнение УЧП

    Вид: \(u_{tt} = a^2u_{xx} + f(x, t)\).

    Формула Даламбера (бесконечная струна, \(u|_{t=0} = \varphi,\ u_t|_{t=0} = \psi\)):

    \[u(x, t) = \frac{\varphi(x - at) + \varphi(x + at)}{2} + \frac{1}{2a}\int_{x-at}^{x+at}\psi(s)\,ds\] \[\qquad + \frac{1}{2a}\int_0^t\!\!\int_{x-a(t-\tau)}^{x+a(t-\tau)} f(\xi, \tau)\,d\xi\,d\tau.\]

    Струна с закреплёнными концами \(u(0, t) = u(l, t) = 0\) — метод Фурье:

    \[u = \sum_{n=1}^{\infty}\left(A_n\cos\frac{\pi nat}{l} + B_n\sin\frac{\pi nat}{l}\right)\sin\frac{\pi nx}{l},\] \[A_n = \frac{2}{l}\int_0^l\varphi(x)\sin\frac{\pi nx}{l}\,dx,\qquad B_n = \frac{2}{\pi na}\int_0^l\psi(x)\sin\frac{\pi nx}{l}\,dx.\]

    Для полуограниченной струны — продолжить начальные данные нечётно (закреплённый конец) или чётно (свободный конец). В пространстве: формулы Кирхгофа (3D) и Пуассона (2D).

    Уравнение теплопроводности (диффузии) УЧП

    Вид: \(u_t = a^2u_{xx} + f(x, t)\), начальное условие \(u|_{t=0} = \varphi(x)\).

    На всей прямой (формула Пуассона):

    \[u(x, t) = \frac{1}{2a\sqrt{\pi t}}\int_{-\infty}^{+\infty}\varphi(\xi)\,e^{-\frac{(x - \xi)^2}{4a^2t}}\,d\xi.\]

    На отрезке \([0, l]\) с \(u(0, t) = u(l, t) = 0\):

    \[u = \sum_{n=1}^{\infty}b_n\,e^{-\left(\frac{\pi na}{l}\right)^2t}\sin\frac{\pi nx}{l},\qquad b_n = \frac{2}{l}\int_0^l\varphi(x)\sin\frac{\pi nx}{l}\,dx.\]

    Неоднородные краевые условия \(u(0,t) = T_1,\ u(l,t) = T_2\): сначала вычесть стационарное решение \(T_1 + (T_2 - T_1)\frac{x}{l}\). Условия на потоки (\(u_x = 0\)) — ряд по косинусам.

    Принцип максимума: максимум и минимум решения достигаются на начальном или граничном множестве.

    Уравнения Лапласа и Пуассона УЧП

    Вид: \(\Delta u = 0\) (Лапласа), \(\Delta u = f\) (Пуассона). Решения уравнения Лапласа — гармонические функции.

    • Теорема о среднем: значение в центре шара равно среднему по сфере.
    • Принцип максимума: max и min — на границе области; отсюда единственность задачи Дирихле.
    • В полярных координатах: \(u_{rr} + \frac1r u_r + \frac{1}{r^2}u_{\theta\theta} = 0\).

    Задача Дирихле в круге \(r \lt R\), \(u|_{r=R} = \varphi(\theta)\):

    \[u = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left(\frac{r}{R}\right)^n(a_n\cos n\theta + b_n\sin n\theta),\]

    где \(a_n, b_n\) — коэффициенты Фурье \(\varphi\). В интегральной форме (интеграл Пуассона):

    \[u(r, \theta) = \frac{1}{2\pi}\int_0^{2\pi}\frac{R^2 - r^2}{R^2 - 2Rr\cos(\theta - t) + r^2}\,\varphi(t)\,dt.\]

    Фундаментальные решения: \(\ln r\) (2D), \(\frac{1}{r}\) (3D). Прямоугольник — разделение \(u = X(x)Y(y)\) с \(\sin\) и \(\sinh\).

    Метод Фурье (разделения переменных) — алгоритм УЧП

    1. Ищем решение однородного уравнения вида \(u = X(x)T(t)\).
    2. Разделяем: \(\frac{T'}{a^2T} = \frac{X''}{X} = -\lambda\).
    3. Решаем задачу Штурма–Лиувилля для \(X\) с краевыми условиями → \(\lambda_n,\ X_n\).
    4. Находим \(T_n\) для каждого \(\lambda_n\).
    5. Суммируем \(u = \sum T_n(t)X_n(x)\), коэффициенты — из начальных условий (разложение в ряд Фурье).
    6. Неоднородное уравнение: ищем \(u = \sum T_n(t)X_n(x)\) и получаем ОДУ на \(T_n\) (метод собственных функций).

    VI. Преобразование Лапласа, численные методы и другие виды

    Операционный метод (преобразование Лапласа) методы

    \(F(s) = \mathcal{L}\{f\} = \int_0^{\infty}f(t)e^{-st}\,dt\). Превращает линейное ОДУ с постоянными коэффициентами в алгебраическое уравнение.

    \(f(t)\)\(F(s)\)\(f(t)\)\(F(s)\)
    \(1\)\(\frac1s\)\(\sin\beta t\)\(\frac{\beta}{s^2 + \beta^2}\)
    \(t^n\)\(\frac{n!}{s^{n+1}}\)\(\cos\beta t\)\(\frac{s}{s^2 + \beta^2}\)
    \(e^{\alpha t}\)\(\frac{1}{s - \alpha}\)\(e^{\alpha t}f(t)\)\(F(s - \alpha)\)
    \(f'(t)\)\(sF - f(0)\)\(f''(t)\)\(s^2F - sf(0) - f'(0)\)
    \(t f(t)\)\(-F'(s)\)\(\int_0^t f(\tau)g(t-\tau)\,d\tau\)\(F(s)G(s)\)
    \(\eta(t - a)f(t - a)\)\(e^{-as}F(s)\)\(\delta(t - a)\)\(e^{-as}\)
    Пример: \(y'' - 3y' + 2y = 0,\ y(0) = 0,\ y'(0) = 1\). \((s^2 - 3s + 2)Y = 1 \Rightarrow Y = \frac{1}{s-2} - \frac{1}{s-1}\). Ответ: \(y = e^{2t} - e^t\).

    Численные методы методы

    Для \(y' = f(x, y)\), \(y(x_0) = y_0\), шаг \(h\):

    МетодФормулаПорядок
    Эйлера\(y_{k+1} = y_k + hf(x_k, y_k)\)1
    Эйлера–Коши (Хойна)\(\tilde y = y_k + hf_k,\ y_{k+1} = y_k + \frac h2\big(f_k + f(x_{k+1}, \tilde y)\big)\)2
    Рунге–Кутты 4\(y_{k+1} = y_k + \frac h6(k_1 + 2k_2 + 2k_3 + k_4)\)4

    где \(k_1 = f(x_k, y_k)\), \(k_2 = f(x_k + \frac h2, y_k + \frac h2k_1)\), \(k_3 = f(x_k + \frac h2, y_k + \frac h2k_2)\), \(k_4 = f(x_k + h, y_k + hk_3)\).

    Метод последовательных приближений (Пикара): \(y_{n+1}(x) = y_0 + \int_{x_0}^x f(t, y_n(t))\,dt\).

    Разностные (рекуррентные) уравнения другие виды

    Дискретный аналог линейных ОДУ — частая тема олимпиад.

    Вид: \(a_{n+2} + pa_{n+1} + qa_n = f(n)\). Характеристическое уравнение \(\lambda^2 + p\lambda + q = 0\):

    • разные корни: \(a_n = C_1\lambda_1^n + C_2\lambda_2^n\);
    • кратный корень: \(a_n = (C_1 + C_2n)\lambda^n\);
    • \(\lambda = r e^{\pm i\varphi}\): \(a_n = r^n(C_1\cos n\varphi + C_2\sin n\varphi)\).

    Частное решение для \(f(n) = P(n)\mu^n\) ищем в виде \(n^sQ(n)\mu^n\) (\(s\) — кратность \(\mu\) как корня) — полная аналогия с ОДУ.

    Пример: Фибоначчи \(F_{n+2} = F_{n+1} + F_n\): \(F_n = \frac{1}{\sqrt5}\left(\left(\frac{1 + \sqrt5}{2}\right)^n - \left(\frac{1 - \sqrt5}{2}\right)^n\right)\).

    Другие виды уравнений (обзор) другие виды

    • Интегральные уравнения Вольтерры \(y(x) = f(x) + \int_a^x K(x, t)y(t)\,dt\): дифференцированием часто сводятся к ОДУ; с разностным ядром \(K(x - t)\) — преобразованием Лапласа.
    • Интегро-дифференциальные: \(y' + \int_0^x y\,dt = f\) — дифференцировать или применять Лаплас.
    • Уравнения с запаздыванием \(y'(t) = f(t, y(t), y(t - \tau))\): метод шагов — на \([0, \tau]\) решаем обычное ОДУ, затем на \([\tau, 2\tau]\) и т. д.
    • Функционально-дифференциальные (например, \(f'(x) = f(1/x)\)): дифференцировать ещё раз и подставлять, чтобы получить ОДУ.
    • Стохастические \(dX = \mu(X, t)\,dt + \sigma(X, t)\,dW_t\) — исчисление Ито (формула Ито: \(df(X) = f'dX + \frac12 f''\sigma^2dt\)).
    • Дробного порядка — с производными Римана–Лиувилля или Капуто; решения выражаются через функцию Миттаг-Леффлера.
    • Нелинейные УЧП: Бюргерса \(u_t + uu_x = \nu u_{xx}\) (замена Коула–Хопфа \(u = -2\nu\frac{\varphi_x}{\varphi}\) даёт уравнение теплопроводности), КдФ \(u_t + 6uu_x + u_{xxx} = 0\) (солитоны), Гамильтона–Якоби, Навье–Стокса.
    • Уравнения Шрёдингера \(i\hbar\psi_t = -\frac{\hbar^2}{2m}\Delta\psi + V\psi\) и Гельмгольца \(\Delta u + k^2u = 0\) — решаются разделением переменных.

    Приёмы для олимпиадных задач олимпиады

    • Трюк с множителем: условие \(f' + f \gt 0\) переписать как \((e^xf)' \gt 0\) — функция \(e^xf\) возрастает. Аналогично \(f' - kf \to (e^{-kx}f)'\).
    • Неравенство Гронуолла: если \(u' \le \beta(t)u\), то \(u(t) \le u(t_0)\exp\int_{t_0}^t\beta\).
    • Теоремы сравнения: если \(y' = f(x, y),\ z' \le f(x, z)\), \(z(x_0) \le y(x_0)\), то \(z \le y\) при \(x \ge x_0\) (при условии Липшица).
    • Закон сохранения: для \(y'' = f(y)\) величина \(\frac{(y')^2}{2} - \int f\,dy\) постоянна — удобно для оценок и доказательства периодичности.
    • Функциональные уравнения: \(f(x + y) = f(x)f(y)\), дифференцируемая \(f\) → \(f' = f'(0)f\) → \(f = e^{kx}\). Дифференцирование по параметру часто превращает функциональное уравнение в ОДУ.
    • Теорема Штурма: между двумя нулями решения \(y'' + q_1y = 0\) есть нуль решения \(y'' + q_2y = 0\), если \(q_2 \gt q_1\) — оценка числа колебаний.
    • Проверка ответа: всегда подставляйте решение обратно и проверяйте потерянные при делении решения.
