# Crypto Trading Bot (учебный проект)

Простой бот для торговли криптовалютой на споте через [ccxt](https://github.com/ccxt/ccxt) (по умолчанию — Binance). Поддерживает бэктест на исторических данных, безопасный paper-trading (симуляция без реальных денег) и live-режим (в том числе на testnet).

> ⚠️ **Дисклеймер.** Это учебный инструмент, а не финансовый совет. Торговля криптовалютой связана с риском полной потери капитала. Ни одна стратегия из этого репозитория не гарантирует прибыль. Прежде чем использовать реальные деньги: (1) прогоните бэктест на разных периодах, (2) обкатайте стратегию в paper-режиме минимум несколько недель, (3) начните live-торговлю с testnet, (4) переходите на реальные деньги только с суммой, потерю которой вы готовы принять.

## Что внутри

- `bot/strategies/` — две стратегии для входа/выхода:
  - **SMA crossover** (`sma`) — трендовая: в рынке, пока быстрая скользящая средняя выше медленной. Хорошо работает на трендах, слабо — на боковике.
  - **RSI** (`rsi`) — контртрендовая: покупка на выходе из перепроданности (RSI < 30 → назад выше 30), продажа при развороте из перекупленности (RSI > 70 → назад ниже 70). Хорошо ловит отскоки на боковике, может рано закрывать позицию в сильном тренде.
- `bot/risk.py` — риск-менеджмент: размер позиции считается так, чтобы срабатывание стоп-лосса теряло не больше `--risk-pct` % от баланса; плюс фиксированные stop-loss / take-profit в процентах от цены входа.
- `bot/backtest.py` — прогон стратегии по истории с учётом комиссии, стоп-лосса и тейк-профита; считает доходность, просадку, win rate, Sharpe.
- `bot/trader.py` — единый движок для paper и live торговли (режим переключается флагом, торговая логика одна и та же).
- `main.py` — CLI с тремя командами: `backtest`, `paper`, `live`.

## Установка

```bash
cd crypto-trading-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt   # или requirements-dev.txt, если нужны тесты
cp .env.example .env
```

Для `backtest` и `paper` API-ключи не нужны — используются публичные данные биржи. Для `live` нужны ключи в `.env` (для начала — testnet-ключи с https://testnet.binance.vision/).

## Веб-интерфейс (для тех, кто не работал с командной строкой)

Есть простая веб-страница с формами и кнопками — не нужно печатать команды каждый раз.

**Первый и единственный ручной шаг:** установи Python 3.10+ с [python.org](https://www.python.org/downloads/) (на Windows при установке обязательно поставь галочку **"Add python.exe to PATH"**).

Дальше просто запускай бота двойным кликом:

- **Windows:** дважды кликни `start.bat`
- **macOS:** дважды кликни `start.command` (если система заблокирует запуск — правый клик → «Открыть»)
- **Linux:** запусти `./start.sh` из терминала (или сделай исполняемым и дважды кликни в файловом менеджере)

При первом запуске скрипт сам установит всё необходимое (это займёт пару минут), затем откроется браузер со страницей бота на `http://127.0.0.1:5000`. Там будет:

- **Вкладка "Бэктест"** — форма с полями (монета, стратегия, даты) и кнопка "Запустить бэктест", результат — таблица с цифрами и график баланса.
- **Вкладка "Paper-трейдинг"** — кнопка "Запустить" включает симуляцию торговли без реальных денег, журнал сделок обновляется сам.

Live-режим (с реальными деньгами или testnet) в веб-интерфейсе пока не сделан специально — начинать стоит с бэктеста и paper-режима; для live используйте команды ниже.

## Бэктест (для тех, кто предпочитает командную строку)

```bash
python main.py backtest --symbol BTC/USDT --timeframe 1h --strategy sma \
    --fast 20 --slow 50 --from 2023-01-01 --to 2024-01-01
```

Пример вывода:

```
=== Backtest: BTC/USDT 1h | strategy=sma ===
Period: 2023-01-01 00:00:00 -> 2023-12-31 23:00:00 (8760 candles)
total_return_pct: 34.2
max_drawdown_pct: -18.5
num_trades: 24
win_rate_pct: 41.7
avg_trade_return_pct: 1.9
sharpe_ratio: 1.1
buy_and_hold_return_pct: 55.3
```

Сравнивайте `total_return_pct` с `buy_and_hold_return_pct` — стратегия должна оправдывать себя (например меньшей просадкой), а не просто проигрывать простому удержанию актива.

Попробуйте RSI-стратегию:

```bash
python main.py backtest --symbol BTC/USDT --timeframe 1h --strategy rsi \
    --rsi-period 14 --rsi-buy 30 --rsi-sell 70 --from 2023-01-01 --to 2024-01-01
```

Поэкспериментируйте с `--stop-loss-pct`, `--take-profit-pct`, `--risk-pct`, разными таймфреймами (`15m`, `4h`, `1d`) и разными монетами.

## Paper trading (симуляция без реальных денег)

```bash
python main.py paper --symbol BTC/USDT --timeframe 1h --strategy sma --capital 1000
```

Бот раз в свечу тянет актуальные данные, считает сигнал и виртуально исполняет сделки. Состояние сохраняется в `state/paper_*.json`, журнал сделок — в `state/paper_*_trades.csv`. Запустите с `--once`, если хотите гонять его по крону вместо бесконечного цикла.

## Live-режим

```bash
python main.py live --symbol BTC/USDT --timeframe 1h --strategy sma --i-understand-the-risk
```

- Требует API-ключи в `.env`. При `USE_TESTNET=true` (по умолчанию) ордера идут на Binance Spot Testnet — реальные деньги не участвуют.
- Флаг `--i-understand-the-risk` обязателен, плюс интерактивное подтверждение `YES` перед стартом.
- **Всегда сначала тестируйте на testnet.** Переключайте `USE_TESTNET=false` в `.env` только когда полностью уверены в стратегии и рисках.

## Ограничения (важно понимать)

- Стоп-лосс/тейк-профит и сигналы проверяются раз в свечу, а не в реальном времени — между проверками цена может уйти дальше, чем задано в риск-параметрах.
- Стратегии рассчитаны только на длинные позиции (spot, без шорта).
- Бэктест не учитывает проскальзывание (slippage) и глубину стакана — на реальном рынке исполнение будет немного хуже.
- Это отправная точка для обучения, а не готовый продакшн-бот. Перед реальными деньгами код и логику стоит проверить самому.

## Как развиваться в трейдинге дальше

1. Пойми матчасть: risk/reward, размер позиции, просадка, разница между трендовыми и контртрендовыми стратегиями.
2. Гоняй бэктест на разных активах/периодах/таймфреймах — ищи, где стратегия ломается, а не только где она работает.
3. Веди дневник сделок в paper-режиме несколько недель, анализируй `state/*_trades.csv`.
4. Переходи на testnet, потом на небольшую реальную сумму.
5. Никогда не рискуй суммой, которую не готов потерять полностью — крипторынок крайне волатилен.
